# portfolioWS

This is a simple interactive world map project I made. The idea is pretty straightforward — you can move your cursor over any country and it shows one unique or interesting fact about it.

If you click on a country, it gives more details like its GDP, GDP per capita, and happiness index.

## what it does

* shows a world map as the main interface
* hover on a country → see a random/unique fact
* click on a country → see some basic stats

## why I made this

I wanted to build something interactive instead of just a normal webpage unlike a business site. Also thought it would be cool to mix geography with some real-world data.
